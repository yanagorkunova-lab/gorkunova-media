# Конструктор КП

Одностраничное приложение для сборки коммерческих предложений в фирменном стиле
Яны Горкуновой. Работает офлайн: скачайте папку и откройте `index.html` в браузере,
сервер не нужен.

## Как пользоваться

1. Заполните имя клиента, тему, дату, срок действия и скидку.
2. Напишите персональную приписку — она попадёт на обложку. Частые варианты
   можно сохранять как шаблоны.
3. Отметьте дополнительные страницы: «Обо мне», «Как мы будем работать»,
   «Мне доверяют», «Почему это нельзя откладывать».
4. Отметьте услуги. Кнопка «Настроить» открывает список позиций внутри раздела:
   там включаются отдельные документы, правятся цены и пишется приписка к странице.
5. Справа сразу видно готовое КП постранично, как оно уйдёт клиенту.

## Кнопки

- **Скачать PDF** — открывает печать браузера, в диалоге выберите «Сохранить как PDF».
  Формат A4, поля и разрывы страниц уже настроены.
- **Скачать Word** — файл `.doc`, который открывается в Word и Google Документах,
  если клиент просит редактируемую версию.
- **Сохранить** — кладёт КП во вкладку «История». Оттуда его можно открыть,
  продолжить правки или сделать копию для другого клиента.

## Где хранятся данные

Всё лежит в localStorage того браузера, где вы работаете: текущее КП, история и
шаблоны приписок. На другой компьютер они не переносятся, наружу ничего не уходит.
История хранит последние 50 КП.

## Как править каталог услуг

Разделы, документы, описания и цены по умолчанию заданы в массиве `CATALOG`
в начале скрипта внутри `index.html`. Раздел с `kind: 'packages'` показывается
тарифными карточками (абонентское сопровождение), остальные — таблицей
«наименование / стоимость». Цены внутри приложения правятся в каждом КП отдельно,
в `CATALOG` лежат только значения по умолчанию.
